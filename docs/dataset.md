# SENTRY-SAR Dataset Specification

## Official Primary Dataset
Google Earth Engine Collection:
`COPERNICUS/S1_GRD`

## Dataset Properties
- **Satellite**: Sentinel-1A and Sentinel-1B
- **Instrument**: Synthetic Aperture Radar (C-band, 5.405 GHz)
- **Product Type**: Ground Range Detected (GRD)
- **Instrument Mode**: Interferometric Wide Swath (IW)
- **Pixel Resolution**: 10m x 10m
- **Polarizations Available**: Dual-polarization VV (vertical transmit/vertical receive) + VH (vertical transmit/horizontal receive)
- **Orbit Passes**: Ascending and Descending
- **Revisit Time**: 6 - 12 days
